# 帅宾 Cookie · 脚本 UI 重设计方案

> 设计语言：**糖果积木（Candy Blocks）** —— 面向游戏悬浮层的新粗野主义（Neo-Brutalism）
> 基准分辨率：1600×900（所有尺寸均为基准坐标，运行时按 `ctx.S` 缩放）
> 配套交互原型：`docs/ui-redesign/prototype.html`（单文件，可直接在浏览器打开）

---

## 1. 设计目标

| 目标 | 说明 |
|---|---|
| 美观 | 告别 QQ2007 复古渐变，统一为「粗描边 + 糖果色 + 硬阴影」的糖果积木语言，高饱和色块在游戏画面上辨识度极高 |
| 易用 | 全部触控目标 ≥ 48px；图标按钮必配文字标签；主操作（开始/停止）永远最大最醒目 |
| 符合用户习惯 | 保留用户已熟悉的两个心智模型：iOS 灵动岛（精简操控）+ 桌面式配置面板（主编辑），交互路径零学习成本 |
| 零迁移成本 | 只改主题令牌与绘制层，Task/Field/NavEntry **描述符一行不改**，设备上已有 `ui.json` 完全兼容 |

## 2. 现状诊断（为什么改）

1. **风格割裂**：灵动岛是 iOS 深色风，面板是 QQ2007 浅蓝渐变风，两套语言并存。
2. **层级偏弱**：面板内「开始脚本」这个最重要的按钮与普通按钮同量级；任务行是纯文字列表，启用与否只有一个 16px 小对勾。
3. **触控偏小**：标题栏窗控按钮 24×18、chip 内边距 8×6，在游戏触屏场景误触率高。
4. **图标无语义**：灵动岛展开后 4 个纯图标按钮无文字，新用户需要猜。

## 3. 设计令牌（Design Tokens）

### 3.1 色彩

| 令牌 | 色值 | 用途 |
|---|---|---|
| `ink` 墨色 | `#211D19` | 全部描边、正文文字、硬阴影 |
| `paper` 纸面 | `#FFF6E5` | 配置面板主背景 |
| `paper-raised` | `#FFFFFF` | 卡片、输入框、开关槽 |
| `candy-yellow` | `#FFC93C` | 品牌主色：标题块、选中态、主按钮 |
| `candy-green` | `#06D6A0` | 运行中 / 成功 / 开始按钮 |
| `candy-blue` | `#4D96FF` | 空闲 / 信息 |
| `candy-orange` | `#FF9F1C` | 已暂停 / 警告 |
| `candy-red` | `#EF476F` | 停止 / 危险操作 |
| `candy-purple` | `#9B5DE5` | 分类点缀（活动） |
| `island-bg` | `#17130C`（97% 不透明） | 灵动岛底色（深色，压得住任何游戏画面） |
| `text-secondary` | `#8A8071` | 摘要、占位、禁用文字 |

**面板内状态文字**（纸面上的深变体，保证 ≥4.5:1）：运行 `#0E9F6E`、暂停 `#C2410C`、空闲 `#2563EB`。

**任务分类色条**：日常 `candy-yellow`、活动 `candy-purple`、维护 `candy-blue`。

### 3.2 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 中文 / 标题 / UI 文案 | 阿里妈妈数黑体（Alimama ShuHeiTi） | 粗黑几何骨架，与粗描边语言同构；打包进 APK 字体内嵌 |
| 数字 / 英文 / 状态计数 | Oxanium | 科技感等宽感数字，灵动岛计数、步进器数值专用 |

字阶（基准 px）：`13` 摘要/标签 · `15` 正文 · `17` 列表标题 · `20` 区块标题 · `24` 面板标题 · `32` 灵动岛主状态。

行高：正文 1.5，标题 1.2。

### 3.3 形状令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `border-sm` | 2px solid ink | chip、小胶囊 |
| `border-md` | **3px solid ink** | 按钮、卡片、输入框、面板（主描边） |
| `radius-sm` | 8px | 输入框、小按钮 |
| `radius-md` | 12px | 卡片、按钮 |
| `radius-lg` | 18px | 配置面板 |
| `radius-full` | 999px | 胶囊、开关、灵动岛 |
| `shadow-sm` | `3px 3px 0 ink` | chip、小按钮 |
| `shadow-md` | `4px 4px 0 ink` | 按钮、卡片、开关 |
| `shadow-lg` | `8px 8px 0 rgba(23,19,12,.35)` | 配置面板（半透明，避免在游戏画面上糊成大黑块） |

**按压反馈（全系通用）**：元素 `translate(+3px,+3px)` 且阴影收敛为 `1px 1px 0`——"积木被按进桌面"的手感，100ms。

### 3.4 间距与触控

- 4pt 栅格：`4 / 8 / 12 / 16 / 24 / 32`
- **触控目标 ≥ 48×48**（游戏场景手指精度低于日常手机使用）；图标按钮可视图形可小，但热区必须够
- 卡片内边距 16，区块间距 24

### 3.5 动效

| 场景 | 时长 / 曲线 |
|---|---|
| 按压 / 开关滑块 / chip 切换 | 100–150ms ease-out |
| 面板开合 | 200ms ease-out（fade + scale 0.98→1） |
| 灵动岛展开/收起 | 300ms easeOutCubic（沿用现有 `easeOutCubic`，行为不变） |
| 灵动岛自动收起 | 无操作 6s（遮挡策略不变） |

## 4. 布局规格

### 4.1 灵动岛（Dynamic Island）

位置、收缩逻辑、6s 自动收起、局部缩放策略**全部沿用现状**（这是经过验证的成熟交互），仅重绘视觉：

```
收起态（胶囊）
┌─────────────────────────────────┐
│  ●  已战斗 12 场 · 胜率 67%      │   高 64，宽随内容（min 240）
└─────────────────────────────────┘   ink 底 + 3px 状态色描边 + radius-full

展开态（卡片）                                    600 × 224，radius 28
┌───────────────────────────────────────────────┐
│              ●  已战斗 12 场 · 胜率 67%          │   状态行：dot 14 + 17px 文案
│                                               │
│      ┌────┐      ┌────┐      ┌────┐      ┌────┐
│      │ ▶  │      │ ⏸  │      │ ⚙  │      │ ✕  │   按钮：64×64 纸面圆角方块
│      └────┘      └────┘      └────┘      └────┘   ink 图标，热区 88×88
│       开始        暂停        设置        关闭     ★ 新增 13px 文字标签
└───────────────────────────────────────────────┘
```

- **状态描边**：空闲 `candy-blue` / 运行中 `candy-green` / 已暂停 `candy-orange`，与状态点同色——远远一瞥即知状态。
- **图标加文字标签**：解决纯图标新用户不可发现的问题（现状痛点 4）。
- 停止图标（运行中时）与关闭按钮使用 `candy-red` 描边强调破坏性。
- 遮挡红线不变：胶囊 y≤80、卡片 y≤210 & x≈520–1080 的识别禁区不写特征。

### 4.2 配置面板（Config Panel）

尺寸沿用现状：`min(72%W, 1040) × min(78%H, 640)`，居中，顶部留 12。最小化折叠为只剩标题栏一条的行为保留。

```
┌─ 面板（paper 底，3px ink 描边，radius 18，shadow-lg）─────────────────────┐
│ 标题栏 64px                                                               │
│  [▮帅宾 Cookie]                    [●运行中]   [—]  [✕]                  │
│   黄底黑字积木块 24px             状态胶囊    44×40 窗控方块               │
├──────────────────────────────────────────────────────────────────────────┤
│ 脚本条 72px                                                               │
│  ● 运行中 · 已启用任务 2/4 (·已自动暂停)           [ 暂停 ] [ ■ 停止 ]     │
│   15px，自动暂停标记为橙色                           次要120×48 主操作140×48│
├───────────┬──────────────────────────────────────────────────────────────┤
│ 导航轨    │  内容区                                                       │
│ 136px     │                                                              │
│ ┌───────┐ │   ┌─ 任务列表页 / 系统页 ────────────────────────────────┐   │
│ │▮任务  │ │   │  （见 4.3 / 4.4）                                    │   │
│ │ 系统  │ │   │                                                      │   │
│ └───────┘ │   └──────────────────────────────────────────────────────┘   │
└───────────┴──────────────────────────────────────────────────────────────┘
```

- **标题栏**：黄底积木块标题 + 右侧状态胶囊 + 两个 44×40 描边窗控方块（— 缩小 / ✕ 关闭）。替换现有蓝色渐变 + 24×18 小按钮。
- **脚本条**：左侧状态摘要（状态点 + 状态文字 + 已启用计数；自动暂停时追加橙色「·已自动暂停」标记，让"为什么脚本停了"可见），右侧主操作。**开始 = 绿底 140×48，停止 = 红底，暂停/继续 = 白底次要按钮**；空闲时暂停钮禁用（40% 透明、无阴影）。
- **导航轨**：136px，条目 48px 高积木块；选中 = 黄底 + 3px 描边 + 硬阴影，未选 = 无底色无边框。

### 4.3 任务列表页

```
内容区（左右两栏：列表 300px + 详情自适应）
┌─────────────────────────┬──────────────────────────────────────┐
│ [全部][日常][活动][维护]  │  王国竞技场        [已启用][日常]      │ ← chip 36px 高，
│ ┌─────────────────────┐ │  ─────────────────────────────────   │   选中=墨底纸字
│ │▮王国竞技场      (◐) │ │                                      │
│ │ 上限10·购买0·奖杯差0 │ │  启用          ┌────┐                │
│ └─────────────────────┘ │                │ ○──┼──┐ 开关 56×32  │
│ ┌─────────────────────┐ │                └────┴──┘             │
│ │▮日常副本        (○) │ │                                      │
│ │ 难度 普通 · 每日 3 次 │ │  每日战斗上限  [ − ][ 10 ][ + ]      │ ← 步进器：
│ └─────────────────────┘ │  自动购买次数  [ − ][ 0  ][ + ]      │   按钮 44×44，
│  左色条=分类色           │  奖杯差阈值    [ − ][ 0  ][ + ]      │   数值框 72×44
│  选中卡=黄边框+硬阴影    │                                      │   Oxanium 18px
└─────────────────────────┴──────────────────────────────────────┘
```

- **任务卡片**（替换纯文字行）：高 84，左侧 6px 分类色条，标题 17px + 摘要 13px（Summary 描述符，现状已有），右侧**大开关**直接控制启用——不必进入详情就能开关任务（现状必须点 checkbox，太小）。
- **详情头部**：任务名 20px + 状态胶囊（已启用=绿 / 未启用=灰）+ 分类胶囊（2px 描边白底）。
- **Form 行高 56**：标签 15px 左列，控件右列；三种控件视觉统一为「3px 描边积木」：
  - `Bool` → **开关**（替换复选框）：56×32，on=绿底滑块右移，off=白底滑块左，150ms。
  - `Number` → **步进器**：`− / 数值 / +` 三段，按钮 44×44。长按 ± 连发（每 120ms）作为增强可选。
  - `Text` → **文本框**：高 44，白底 3px 描边，聚焦时 4px `candy-yellow` 外发光。

### 4.4 系统页

两张卡片纵向排列，把「保存」与「清缓存」做风险分级：

- **配置持久化卡**：说明文字（配置文件路径，13px 灰）+「保存配置」黄底主按钮，操作结果以行内反馈条显示（成功绿 / 失败红，2px 描边）。
- **危险区卡**（2px `candy-red` 描边 + 浅红底 `#FDE8EE`）：「清除缓存」红底按钮 + 一句后果说明（停止脚本、删除配置与业务缓存、恢复默认）。二次确认：点击后按钮变为「确认清除？」3 秒内再点生效。

## 5. 状态机与交互流（行为不变，仅补充表达）

```
            ┌──────────┐  开始   ┌──────────┐  暂停   ┌──────────┐
            │  空 闲   │ ───────▶ │  运行中  │ ───────▶ │  已暂停  │
            │ (蓝)     │ ◀─────── │ (绿)     │ ◀─────── │ (橙)     │
            └──────────┘  停止    └────┬─────┘  继续   └──────────┘
                                       │ 打开面板（遮挡策略）
                                       ▼
                              已暂停 + 「已自动暂停」标记
                              关闭面板 → 自动恢复运行中
```

- 灵动岛运行中显示 `StatusSource.Text()`（如「已战斗 12 场 · 胜率 67%」），空闲/暂停回退「标题 · 状态」——沿用现状。
- 从面板点「开始」→ 面板自动关闭回游戏（沿用 `renderScriptBar` 现状）。
- 运行中打开面板 → 自动暂停并在脚本条给出橙色标记；关闭面板 → 自动恢复（沿用 `Shell.OpenPanel/ClosePanel`）。
- 手动暂停/继续优先于自动暂停（沿用 `PauseResume`）。

## 6. 可达性与触控

| 项 | 规格 |
|---|---|
| 对比度 | 墨色 on 纸面 ≈ 14.5:1（AAA）；墨色 on 黄/绿/橙 ≥ 7:1（AAA）；彩色块上**一律用墨色文字**，不用白字（黄/绿底白字对比度不达标，这是换糖果色体系的硬约束） |
| 触控目标 | 全部 ≥ 48×48；灵动岛展开按钮热区 88×88 |
| 状态双编码 | 状态 = 颜色 + 文字/图标形状，不单独依赖色相（色弱友好） |
| 字号下限 | 13px（仅摘要/辅助），正文 ≥ 15px |
| 反馈 | 每个操作 ≤100ms 内给出视觉反馈（按压位移 / 开关滑动 / 反馈条） |

### 7.4 硬阴影在 ImGui 的实现

ImGui 无 box-shadow，用 DrawList 双矩形模拟：先画偏移 `(4,4)` 的 ink 实心矩形，再在其上画本色矩形 + 3px 描边。按压态 = 本色矩形偏移 `(3,3)` 且底矩形偏移 `(1,1)`。灵动岛深色浮层可省略底矩形（深色自带分量）。
