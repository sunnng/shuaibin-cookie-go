② 主循环与调度

  • • 每轮：stop → guard.Check → scheduler.Run → sleep

  • • 注册顺序 = 优先级，第一个 Condition==true 的任务先跑
  • • 无活时取各 idleProvider 最大 remain，带 guard 分段睡眠

③ 状态机范式

  • • 环形模板：detect→sync→check→(干一步)→sync→…→leave→Done
  • • sync 是循环锚点：每次执行后回这里重新同步状态
  • • check 集中所有结束/分支判断，leave 是唯一正常出口
